# 연결 설계실

뉴런 하나는 XOR을 못 푼다? — 연결로 문제를 푸는 두 가지 지능형 모델, 그래프 알고리즘과 인공 신경망을 손으로 체험하는 앱입니다. 한 단계씩 따라가는 다익스트라와 이완, 음수 간선에서 갈리는 다익스트라와 벨만 포드(음수 사이클 경고), 경로를 하나씩 더하는 최대 흐름과 최소 절단, 거점을 막아 보는 매개 중심성, 손잡이로 만드는 AND·OR·NAND 퍼셉트론과 XOR의 선형 분리 불가(무작위 10만 번 시도), 은닉층 OR+NAND→AND로 푸는 XOR, 시그모이드 기울기 소실과 ReLU, 역전파로 XOR을 배우는 작은 신경망까지 담았습니다. 지능 08 부록이며, 파일 하나(`index.html`)로 인터넷 없이 동작합니다.

## 구성
- ① 최단 경로: 1969년 XOR 사건, 다익스트라 단계 실행, 퀴즈 ①(4), 벨만 포드와 음수 사이클
- ② 흐름·거점: 포드 풀커슨 경로 추가(5 → 15)와 최소 절단, 매개 중심성과 거점 막기
- ③ 퍼셉트론: 가중치·편향 슬라이더와 결정 경계, 퀴즈 ②(AND), XOR 무작위 10만 번 시도
- ④ 은닉층: XOR 신경망 신호 따라가기, 활성화 함수와 기울기 소실, 역전파 학습, networkx 코드, 세 줄 정리, 생각해 볼 질문
